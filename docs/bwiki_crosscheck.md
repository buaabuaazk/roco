# BWIKI 与 rocom-data 交叉核验

比较本地 BWIKI 正式转换结果与 `../rocom-data` 已提交的数据快照。
本次只读核验，采集资料、SQLite、Agent 和对方仓库保持原样。
详细差异见同目录 `bwiki_crosscheck.json`；重复执行命令：

```sh
conda activate hello-agents
python scripts/crosscheck_bwiki.py
```

## 数据范围与匹配标准

- 对方仓库提交：`d2c0533`。`sprites.json`、`skills.csv` 的最近修改提交为 `852b20d`，提交时间为 2026-05-07 00:26:20 +08:00；这是 Git 修改时间，实际采集时间尚未确认。
- 对方 `sprites.json` 为 465 条，我方 `converted/pets` 为 633 条，均包含形态条目。
- 用图鉴编号和名称匹配，统一 Unicode 罗马数字等表示；多形态优先完整标题，再比较形态。匹配 456 条，9 条未匹配，0 条歧义。未匹配条目单列，不作为数值错误。
- 技能 CSV 没有游戏 ID，按唯一技能名称匹配；描述只忽略空白和常见标点，保留所有数值与效果措辞差异。
- 明确映射双方不同的速度/魔防字段；对状态和防御技能，零威力与缺省威力视作同种表示。
- 扫描已保存的全部正式文件；批次 manifest 仅代表最近一次选择范围，不作为完整目录。

## 结论与边界

现有证据支持：两份数据的许多差异对应后续版本改动，对方已提交快照适合做历史交叉参考，不宜直接覆盖我方当前数据。
双方主要源自 BWIKI，属于同类来源的版本与解析一致性核验。历史表同样由 BWIKI 维护，匹配历史记录并不构成官方独立验证。
奔乐鹿、波普鹿、古卷匣魔像技能等级及未匹配条目等差异保留待核查，数据保持原样。
