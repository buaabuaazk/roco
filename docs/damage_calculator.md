# 伤害计算器（社区估算版）

网页入口：左侧「伤害计算」，地址 `http://127.0.0.1:8765/#damage`。
网页默认使用精灵配置模式，提供双方精灵、星级、成长等级、个体、性格、技能和战斗Buff的手动选择。切换到直接输入模式时保留本页配置。
伤害核心与 Agent 的 `calculate_damage` 工具共用 `roco_data/damage.py`；网页的精灵面板配置由独立接口处理。

## 直接输入数值模式

1. 输入攻击方的强化前实际攻击、目标的强化前实际防御，以及本次技能基础威力。
2. 可从本地技能列表填入威力，并核对物攻/物防或魔攻/魔防通道与技能触发条件。
3. 填写等级、本系、克制、威力加成、攻防强化及最终伤害倍率。
4. 点击计算查看七步结果。当前生命选填，可展示伤害占比和估算击倒判断。

实际能力值采用游戏面板数值。种族值用于描述精灵潜力，实际能力值换算另行核验。
本系、克制和特殊效果倍率由使用者根据本次对战确认。百分比输入框填写50表示50%，API和工具对应小数0.5。
最终倍率为最终伤害修正的合计值，例如70%减伤填写0.3；多个独立减伤项需先合并为对应倍率。

## 规则

依据已保存的 `data/mechanics/damage_formula.json`，并于2026-11-11核对
[Roco Showdown社区使用指南](https://roco-showdown.com/battle-use-guide)。该来源是社区实现，规则状态为待游戏内实测验证。

- 有效威力：固定加值叠加到基础威力后，再乘本次技能威力加成；结果最低取0。
- 攻防倍率：攻击提升与防御降低加入分子，攻击降低与防御提升加入分母。
- 显示威力：有效威力叠乘本系、克制、攻防倍率和其他威力倍率后四舍五入。
- 等级系数：`(等级 × 0.45 + 10) / 41`。
- 基础伤害：实际攻击、显示威力与等级系数相乘后四舍五入，再除实际防御并向下取整。
- 最终估算：基础伤害乘最终伤害倍率。

四舍五入采用十进制半数进位，最终乘区后保留小数。半数边界与最终取整方式待实测。
当前按单次普通伤害结算。特殊技能的固定伤害、变威力、免疫、特性、天气、连击及随机效果需逐项核对并换算为适用输入。

“载入公式示例”使用社区示例的实际攻击234、防御226、威力75、固定威力20、威力加成50%、本系1.25、克制2、60级，得到显示威力356、最终估算332。

## 接口和工具

- `GET /api/damage/skills`：本地具有数值威力的攻击技能，供表单选择。
- `POST /api/damage/calculate`：按表单参数计算，返回输入快照、七步过程、估算值及验证状态；参数错误返回422。
- `calculate_damage`：Agent工具，必填 `attack`、`defense`、`base_power`；等级默认60，其余倍率默认1、加成默认0，`defender_hp`选填。

```json
{
    "attack": 234,
    "defense": 226,
    "base_power": 75,
    "level": 60,
    "flat_power_bonus": 20,
    "power_percent_bonus": 0.5,
    "stab_multiplier": 1.25,
    "type_multiplier": 2,
    "defender_hp": 411
}
```

## 网页精灵配置模式

默认进入「精灵配置 · 60级PVP」；「直接输入数值」保留原有参数表单。

1. 搜索并选择攻击方和受击方的具体精灵形态。阿布、冥古龙及其进化链显示“实际入场等级”，可填1～100的整数，默认60；其他精灵固定60级，切换回普通精灵时重置为60。双方面板分别使用各自等级，伤害等级系数使用攻击方等级。技能池仍按60级可学习范围提供，入场等级用于特性生效后的战斗能力换算。
2. 默认60级／5星／成长50。双方星级可独立填写0～10、成长等级0～100，成长等级至少为星级的10倍。个体值采用0～60整数，最多3项非零；默认全部为0，每项可点击“拉满”填60，也可输入中间整数以配置未满资质的精灵。性格提升为10% + 2% × 星级，降低恒为10%，正面提升和负面降低分别选择，能力项应不同；两项均选“无修正”表示中性配置。页面展示每项种族值与换算面板。
3. 从攻击方的本地技能池选择一个具有数值威力的物攻或魔攻技能，显示升级、技能石、血脉和传说等学习条件。升级技能限定记录等级不高于60；血脉与传说的具体资格按游戏内配置确认。
4. 技能决定物攻/物防或魔攻/魔防通道，本系倍率自动匹配攻击方属性，克制倍率读取受击方已合并的本地克制表（保留3倍、0.25倍等组合结果）。
5. 受击方当前生命比例由估算最大生命换算；可以手动覆盖本次基础威力，并填写强化、威力与最终乘区等修正。

面板换算由服务端统一执行，采用[Loy Showdown面板说明](https://loyshowdown.com/app/articles/54192c55-0c93-4cd4-926c-027174b807d5)第3.1、9节的等级公式：公式个体直接采用输入的0～60整数，core = 2 × 种族值 + 公式个体；HP先计算(core / 100) × (等级 + 25) + 等级 + 10，其他属性先计算(core / 200) × (等级 + 50) + 10。每一步落为float32，先除后乘，取整后乘性格、再次取整，最终HP加2 × 成长等级、其他属性加成长等级。取整采用floor(x + 0.5)。面板规则保留社区估算验证状态；伤害链继续使用上文记录的现有社区规则。特性资料展示在精灵卡片中，本次触发效果通过战斗Buff配置。结果保留双方面板、技能、攻防通道与所有计算输入的快照。

新增网页接口：

- `GET /api/damage/pets`：可选择的精灵及形态，`level_editable`标记是否可填写入场等级。
- `GET /api/damage/pets/{pet_id}/skills`：指定精灵的攻击技能与学习条件。
- `POST /api/damage/panel`：预览一只精灵的面板及当前生命；`level`默认60，非60仅对上述进化链开放；`stars`默认5，`growth`默认50，响应包含实际使用的星级与成长等级。
- `POST /api/damage/matchup`：按双方配置和技能计算；自动生成攻防值、本系与克制倍率，修正参数仅允许开放的额外修正项。

上述接口用于网页手动配置；Agent 的原有数值计算工具保持独立。

实测回归：贝古斯60级魔攻203，冥古龙89级魔防148，灵媒威力100、幽系克制2倍，其余修正为默认值，估算伤害247。

## 战斗Buff

精灵配置模式用“战斗Buff”条目替代原来的修正合计输入。添加条目后选择所属精灵和效果，填写每层幅度及层数，可暂停或移除。每层幅度根据当场游戏效果填写；默认层数为1，幅度必填。当前面板保持强化前数值，Buff参与下方伤害计算，结果列出采用的条目与实际汇总修正。

规则目录：`data/mechanics/buffs.json`；解析：`roco_server/buffs.py`。当前提供19种效果，包含物攻/魔攻/物防/魔防及双攻/双防的提升与降低、固定威力、普通威力提升/降低、独立威力增幅、造成伤害提升、受到伤害提升和减免。前端读取目录，不填写底层计算参数名。

- 能力项：每层百分比×层数；同类相加；物攻命中仅采用攻击方物攻和受击方物防，魔攻命中采用魔攻/魔防。双攻/双防据通道选择对应能力。增益与减益分别累加到现有社区攻防倍率的分子和分母。
- 固定威力：每层点数×层数相加，可为负值。
- 普通威力：提升与降低按带符号的百分比相加，交给已有威力公式计算。
- 独立威力：每条换算为`1 + 每层百分比×层数`，不同条目相乘。
- 最终乘区：攻击方“造成伤害提升”、受击方“受到伤害提升”和“受到伤害减免”分别换算为`1 + 合计比例`或`1 - 合计比例`，不同条目相乘。同一条减免按层数线性累计，上限100%。独立来源拆为多条，例如两条20%减免为0.8×0.8；同一条20%×2层为0.6。叠加方式仍按已确认的实际效果选择，并保留社区估算状态。
- 所属方或通道不适用的条目保留在结果里并说明原因；层数0为未生效。页面暂停的条目保留草稿，提交时略过。
- 每次最多32条，层数0～100整数；每层幅度须为有限数值。后端同时验证单条与汇总后的参数范围。
- 特性、技能、天气等触发条件由玩家先确认，本次仅处理当前生效的Buff快照。自动生成特性Buff后续接入同一解析函数。

接口：`GET /api/damage/buffs`返回规则目录；`POST /api/damage/matchup`新增可选`buffs`数组。原有`modifiers`参数继续可用，表示额外修正，与Buff汇总合并；调用方应把同一效果记录一次。响应新增`buffs`（生效明细）及`resolved_modifiers`（实际汇总修正）。

```json
{
    "side": "attacker",
    "kind": "dual_attack_boost",
    "value": 20,
    "layers": 3,
    "enabled": true
}
```

此条表示攻击方双攻提升20%×3层，物攻与魔攻命中均计入攻击提升60%。技能变属性、连击、反伤和致命保留1血按独立结算规则继续扩展。
