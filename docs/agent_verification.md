## 真实接口抽样

| 场景 | 已观察到的行为 |
|---|---|
| 喵喵特性查询 | 模型执行查询，返回氧循环及“使用草系技能后回复 10% 生命” |
| 毒沼学习关系 | 模型查询技能和精灵关联，得到技能石来源、威力 80、能耗 2 |
| 连续追问“它的特性是什么” | 沿用上一轮的喵喵对象，执行特性分区查询 |
| 喵喵与迪莫速度种族值比较 | 执行比较工具，回答 33、92，差值 59 |
| 新会话中的“它怎么进化” | 先询问具体精灵对象 |
| 喵喵进化到喵呜 | 查询进化分区，得到等级 16、魔法粉尘 5、向阳花 2、费用 10000 |

抽样期间出现过临时模型连接失败；程序返回 `model_error`，重试后完成了技能关联与追问流程。
执行记录显示失败轮次保持原有成功历史，缺少明确对象的后续提问会进入澄清。

## 联调后调整

- 特性查询直接使用 `features`，工具提示区分特性内部 ID 与可学习的战斗技能。
- 来源记录按所查询分区优先选择，聚合分区采用 `pet-detail` 来源。
- 学习关系的空条件字段表达为资料缺项；学习方式、具体操作、费用单位等采用来源明确提供的内容。
- 提示词约束回答聚焦玩家问题，以实际条件与结果正面表达。
