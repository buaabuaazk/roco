# 特性与伤害计算：本地资料核查

核查日期：2026-11-14。逐条阅读本地262条特性，并关联662条精灵/形态记录。本文描述当前采集快照，机制与乘区仍保留社区估算状态。

本次仅整理资料与计算器覆盖情况，后续实现以此为输入。各组允许同一特性重复出现；状态、印记组为代表清单。代表精灵列最多列3项，同一特性的完整关联可在正式JSON中查询。

## 对当前计算器的影响

- 等级：阿布、冥古龙及其进化链可手填实际等级；攻防面板和攻击方等级系数据此计算。
- 等级附带效果：阿布/超能阿布低于80级受伤+30%，冥古龙低于80级受伤+40%；超能阿布战斗中每提升1级获得物攻+5%。这些条件效果目前通过战斗修正手填。
- 能力值：现有攻击提升/降低、防御提升/降低输入可承载已确认的汇总修正；状态层数、触发先后、消失与保留均需记录。
- 威力：固定加值、威力百分比、其他威力乘区可手填；特性增幅与其他效果的叠加乘区需要逐项验证。
- 承伤：最终倍率可承载已确认减伤/增伤；免疫可按0伤害处理。致命保留1血需依据当前血量做特殊结算。
- 技能属性变化会同时改变本系与克制；应在查询技能后、计算倍率前解析。
- 连击/额外使用、反击、印记与持续扣血属于额外结算；需要分别展示单次命中、额外伤害及总扣血。
- 种族资质提升优先使用对应形态已有种族值；具体提升量应与形态资料核对，避免在已提升的数据上再次叠加。

## 条件字段建议

| 条件来源 | 需要记录的状态 |
| --- | --- |
| 本次技能 | 系别、物攻/魔攻、当前威力、当前/基础能耗、技能栏位置、迸发/选择/传动等效果 |
| 双方配置 | 实际等级、种族与能力值、携带技能、血脉、当前/最大生命、能量、增减益种类与层数 |
| 场地与时序 | 天气、环境、当前回合、先后手、是否首回合、上回合使用的技能系别 |
| 战斗历史 | 聚能/切换/应对/消耗能量次数、队伍曾用技能、击败与力竭数量、上次攻击后的重置 |

技能效果的“使用后”“回合结束后”通常影响后续攻击；当前一击的适用时点按资料与实测确认。
